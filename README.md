# IP-Symcon Bewegungsmelder-Modul

Diese Bibliothek soll bestehende Bewegungsmelder-Abläufe durch konfigurierbare IP-Symcon-Instanzen ersetzen.

## Projektstatus

Das Modul befindet sich in Entwicklung. Installations- und Bedienungsdokumentation folgen mit der Implementierung.

## Voraussetzungen

- IP-Symcon 8.1 oder neuer
